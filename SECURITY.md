# Security and Safety

This project controls a power-electronic motor driver. A software defect can cause unexpected motion, excessive current, MOSFET failure, overheating, or damage to connected equipment.

Until a private reporting channel is configured, report non-sensitive defects through the repository issue tracker. For a vulnerability or safety defect that would be dangerous to publish before a fix exists, use GitHub's private security-advisory feature after the repository is created.

Please include the board revision, firmware revision, supply voltage, motor/load state, reproduction steps, and whether the bridge can still be disabled.

The project is experimental and is not designed, certified, or warranted for safety-critical applications.
